# Репозиторий разделён на два независимых проекта

Вы правы: проект про презентации и проект **«Гранты»** — это разные продукты.
Сейчас они разделены и не мешают друг другу.

## Структура
- `presentation-generator/index.html` — проект генератора презентаций.
- `grants/index.html` — MVP-помощник НКО для работы с грантами.
- `index.html` — стартовая страница-навигация по двум проектам.

## Что уже реализовано в «Гранты»
- Выбор источников сигналов: ВК, Telegram, local news, отзывы из форм, новости.
- Анализ сигналов и ранжирование проблем по тематикам.
- Подбор грантодателей из заданного списка:
  - Фонд президентских грантов,
  - Президентский фонд культурных инициатив,
  - Региональные гранты + софинансирование ФПГ,
  - Фонд Потанина,
  - Гранты Минпросвещения.
- Генерация черновика заявки и экспорт в `.docx`.
- Расчёт напоминаний о дедлайнах за 5 дней (email/telegram канал).

## Локальный запуск
```bash
python3 -m http.server 4173 --directory /workspace/test
```

Откройте:
- http://localhost:4173/index.html

Далее можно перейти в каждый проект отдельно:
- http://localhost:4173/presentation-generator/index.html
- http://localhost:4173/grants/index.html
