# Генератор презентаций для интеллектуальных игр

Ниже — максимально простой пошаговый сценарий: где взять код, как открыть приложение и где потом искать скачанную презентацию.

## 1) Где код и как его «скачать/скопировать»

У вас есть 2 варианта.

### Вариант A — код уже у вас локально
Если у вас есть папка проекта (например, `/workspace/test`), ничего скачивать не нужно.
Просто откройте файл:

- `index.html`

### Вариант B — скопировать код файла вручную
1. Откройте `index.html` в текстовом редакторе.
2. Скопируйте весь текст файла.
3. Создайте у себя новый файл с именем `index.html`.
4. Вставьте код и сохраните.
5. Открывайте этот `index.html` в браузере.

---

## 2) Как открыть приложение

### Способ 1 (быстрый)
- Дважды кликните по файлу `index.html`.
- Он откроется в браузере как локальная страница (`file:///.../index.html`).

### Способ 2 (рекомендуется)
Запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 4173 --directory /workspace/test
```

После этого откройте ссылку:

- http://localhost:4173/index.html

---

## 3) Как сделать презентацию

1. Заполните поля: название игры, тему, настроение, возраст.
2. Выберите количество вопросов (от 10 до 12).
3. Отметьте идеи игры (чипы) и при желании добавьте свои идеи через запятую.
4. Нажмите **«Обновить предпросмотр»** — увидите структуру слайдов.
5. Нажмите **«Сгенерировать презентацию (.pptx)»**.

---

## 4) Где скачать готовый `.pptx`

После нажатия кнопки генерации браузер автоматически скачает файл презентации.

Обычно файл появляется в папке:
- `Загрузки` / `Downloads`

Имя файла:
- `<Название_игры>_quiz.pptx`

Пример:
- `Квиз-Бум_quiz.pptx`

---

## 5) Почему может «не скачиваться»

Проверьте:
1. Не заблокировал ли браузер скачивание (иконка загрузок/предупреждений справа сверху).
2. Разрешены ли загрузки для вкладки.
3. Нет ли строгого режима блокировки всплывающих окон/скачиваний.

---

## 6) Мини-проверка, что всё работает

1. Откройте страницу `http://localhost:4173/index.html`.
2. Нажмите кнопку генерации.
3. Убедитесь, что в `Downloads` появился `.pptx` файл.
