Основные данные проекта

Что собрать для каждой комнаты

  • Параметры: площадь, высота, окна/двери, солнечная ориентация.
  • Функционал: сценарии использования, хранение, техника.
  • Палитра: 3–5 базовых цветов + акценты, подбор материалов.
  • Мудборд: референсы, материалы, текстуры.
  • 3D: ракурсы, задачи для визуализатора, дедлайн.
  • ТЗ для строителей: уровни полов, потолки, инженерия.
  • Схемы: электрика, свет, мебель, сантехника, вентиляция.

Комнаты и задачи

Технические аспекты и схемы

  • Электрика и слаботочка: розетки, группы, трассы Wi‑Fi, роутер.
  • Свет: общий, акцентный, подсветка, сценарии и управление.
  • Отделка: уровни полов, стыки покрытий, примыкания, плинтус.
  • Сантехника: выводы воды/канализации, трапы, ревизии.
  • HVAC: вентиляция, приточка, кондиционеры, дренаж.
  • Чертежи: планы расстановки мебели, потолков, развёртки стен.

Гайд для визуализатора

  • Палитра и материалы по каждой комнате (покрытия, текстиль, свет).
  • Углы съёмки: общий вид, ключевая стена, зоны хранения.
  • Ссылки на референсы и мудборд, общая атмосфера.
  • Комментарии по мебели на заказ, зазоры, подсветка, фурнитура.
  • Формат выдачи: 4K+, ratio 16:9/9:16, срок и количества ракурсов.

Соберите всё в одном месте — визуализатору не придётся искать детали в переписке.

Инструкции для строителей

  • Старт: перепланировка, демонтаж, возведение перегородок.
  • Инженерия: электрика, вода, вентиляция, кондиционирование.
  • Черновая отделка: выравнивание, шумоизоляция, тёплый пол.
  • Чистовая: покрытие полов, покраска/обои, плитка, потолки.
  • Финиш: установка света, сантехники, дверей, мебели и текстиля.

Добавляйте комментарии прямо в задачи комнаты, чтобы подрядчик видел связку с планом.
